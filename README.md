# Data Analysis Portfolio

A collection of analytical work demonstrating practical data cleaning, exploratory analysis, statistics, visualization, and insight generation.

## Purpose

This repository contains analysis work developed across different datasets and analytical questions. Individual notebooks or scripts should be read alongside their data sources and methodology.

## Analytical workflow

```text
Data Source
   ↓
Data Cleaning
   ↓
Validation
   ↓
Exploratory Analysis
   ↓
Statistical Analysis
   ↓
Visualization
   ↓
Insights
```

## Skills demonstrated

- Python-based data analysis
- Data cleaning and preparation
- Exploratory data analysis
- Descriptive statistics
- Data visualization
- Analytical storytelling
- Reproducible notebook workflows

## Repository guidance

Each analysis should document its dataset, analytical question, transformations, assumptions, key findings, and limitations. Results should be interpreted from the actual calculations rather than inferred from chart appearance alone.

## Reproducibility

Use the notebooks/scripts and source data included in the repository where available. A dependency file should be added for analyses that require third-party Python packages.
